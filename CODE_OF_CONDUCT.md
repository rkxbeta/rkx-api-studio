# Code of Conduct

RKX API Studio is built in the open, and we want everyone to feel welcome taking part: in issues, pull requests, discussions and reviews.

## Our standards

Please:

- be respectful, patient and constructive, including when you disagree;
- assume good intent and ask before assuming;
- give feedback about code and ideas, not about people;
- respect people's time and privacy;
- accept that maintainers may decline a contribution, and explain why when we do.

Not acceptable:

- harassment, insults, or personal or political attacks;
- discriminatory language or imagery of any kind;
- sexual content or unwelcome sexual attention;
- publishing someone's private information without their explicit permission;
- trolling, spam, or repeated off-topic or promotional posts;
- any conduct that would be inappropriate in a professional setting.

## Scope

This Code of Conduct applies in all of this project's spaces: the GitHub repository (issues, pull requests, discussions, reviews and commits) and any place where someone represents the project.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately through <https://rkxbeta.com/contact> and mention "RKX API Studio Code of Conduct". Reports are handled confidentially.

## Enforcement

Maintainers may edit or remove comments, commits, issues and other contributions that break this Code of Conduct. They may also warn, temporarily restrict or permanently ban anyone whose behaviour is harmful. Decisions take the impact on the community into account, and we try to be fair and proportionate.
